# Саморевью по openapi.yaml

- Ресурсы в path - существительные kebab-case
- id конкретного ресурса находится в path
- версия api указана в servers
- POST создания нового ресурса возвращает 201
- DELETE не возвращает ничего при успешном удалении
- Ошибка 409 при бизнес-ошибке
- Ошибка 422 при ошибке валидации
- Все ошибки имеют единый ErrorResponse
- Для 422 есть example
- Для коллекций есть фильтры, пагинация, сортировка
- limit имеет default и maximum
- Операции имеют описание, теги и summary
- Есть примеры удачного запроса и ошибки
- Схемы подключены через $ref
- Файл валидируется без ошибок
